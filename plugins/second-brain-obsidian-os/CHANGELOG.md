# Changelog

Format follows [Semantic Versioning](https://semver.org/): MAJOR.MINOR.PATCH.

## [1.0.0]
First public release of the OS-only edition of `second-brain-obsidian`: the five
vault skills (`os-setup`, `os-optimizer`, `os-operator`, `os-mcp`, `team-os`) without the
consulting delivery skills. It uses its own plugin id (`second-brain-obsidian-os`), so it
can be installed alongside, or instead of, the full package.
