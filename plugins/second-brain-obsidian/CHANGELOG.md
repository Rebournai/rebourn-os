# Changelog

Format follows [Semantic Versioning](https://semver.org/): MAJOR.MINOR.PATCH.

- **MAJOR**: breaking change to vault structure, skill names, or how a skill is invoked.
- **MINOR**: new skill, new capability, or meaningful new behaviour in an existing skill.
- **PATCH**: wording fixes, doc corrections, small non-behavioural tweaks.

## [2.0.2]
First public release of the Second Brain (Obsidian) plugin: vault skills
(`os-setup`, `os-optimizer`, `os-operator`, `os-mcp`, `team-os`) and client delivery
skills (`client-onboarding`, `ai-opportunity-assessment`, `client-report`,
`engagement-tracker`).
