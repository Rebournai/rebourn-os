# Default categories and priorities

Starting points only. Merge with the profile's `Categories.md`, then `Rules.md`. The profile always wins over these defaults.

Priority scale: **Urgent** (act today, a deadline or loss is at stake), **High** (reply within a business day), **Normal** (this week), **Low** (batch or ignore).

## Universal (all segments)

| Category | Default priority | Default action |
|---|---|---|
| Security alert / suspicious | Urgent | Flag, do not click or reply, tell user |
| Time-sensitive deadline | Urgent/High | Surface in digest with the date, extract task |
| Direct question from a real person | High | Draft reply (if allowed) |
| Receipts and confirmations | Low | Label, no reply |
| Notifications from tools | Low | Label, summarize in counts |
| Newsletters and promotions | Low | Label, archive only if approved |
| Cold sales outreach | Low | Label, no reply unless profile says otherwise |
| Spam / phishing | Low (flag) | Never open links, flag, no reply |

## E-commerce

| Category | Default priority | Default action |
|---|---|---|
| Chargeback / dispute / payment failure | Urgent | Surface with deadline, no auto-draft of evidence claims |
| Fraud / suspicious order | Urgent | Flag, escalate |
| Damaged / wrong / missing item | High | Draft empathetic reply, request photos if policy says so, placeholders for resolution |
| Return / refund / exchange request | High | Draft per return policy, no promise of refund unless policy and user allow |
| Order status (WISMO) | Normal/High | Draft with tracking if lookup connected, else placeholder |
| Cancellation / address change | High | Time-sensitive until shipped; surface fast |
| Shipping delay from carrier / 3PL | High | Surface, group affected orders |
| Wholesale / B2B inquiry | High | Draft reply with next step, flag as revenue |
| Influencer / affiliate / partnership | Normal | Draft or label per profile |
| Pre-sale product question | Normal | Draft; do not invent specs |
| Discount code problem | Normal | Draft per policy |
| Review notifications | Low | Count; low ratings surface as High |
| Platform / app / processor notices | Normal | Summarize; billing or policy changes High |
| Supplier / manufacturer | Normal | Surface stock, price, lead-time changes |

Repeat contact on the same order, abusive tone, or legal / press language raises priority one level and is flagged for the owner.

## Small business

| Category | Default priority | Default action |
|---|---|---|
| New lead / inquiry | High | Draft reply with next step and booking link if provided |
| Quote / proposal request | High | Draft clarifying questions; no pricing unless profile allows |
| Client project message | High | Summarize, extract tasks, draft |
| Scheduling / meeting request | Normal | Draft with availability only if a calendar is connected |
| Invoice received (to pay) | High if due soon | Extract amount, due date as task |
| Payment reminder / overdue | High | Surface, never auto-pay |
| Contract / legal | High | Flag, per sensitive policy |
| Hiring / applications | Normal | Label, summarize |
| Vendor / supplier | Normal | Surface changes |
| Accounting / tax | Normal/High near deadlines | Extract dates |

## Personal

| Category | Default priority | Default action |
|---|---|---|
| Bills and payment due | High | Extract amount and due date as task |
| Travel and bookings | High near date | Extract dates, confirmation numbers into digest |
| Appointments | High near date | Extract as task |
| Banking / tax / government | High | Flag only |
| Health portal | Normal | Flag only |
| Family and friends | Normal | Draft in personal voice |
| Work-related | Normal | Per profile |
| Shopping and delivery | Low | Surface delivery issues |
| Social notifications | Low | Count |
| Newsletters and promos | Low | Label, propose unsubscribes |
